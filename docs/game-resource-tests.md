# Тесты с ресурсами игры

Ресурсы берутся из уже добавленного пользователем архива
`q 92 20251201y.jar.zip`. Оригинал не распаковывается в исходники и не
перезаписывается. Никаких ресурсов из интернета скрипты не скачивают.

## Подготовка тестового classpath

```sh
python scripts/game_resources.py --archive 'q 92 20251201y.jar.zip'
```

Результаты по умолчанию в игнорируемом `build/game-resources/`:

- `resources.jar` — только ресурсы, без старых классов и `META-INF`;
- `resource-report.json` — перечень файлов с SHA-256, размеры PNG и параметры
  уровней, включая конфигурацию неба.

Пути с выходом за корень, дубликаты ресурсов и слишком большие архивы
отклоняются. Бинарные данные, имена с пробелами, CRLF и кодировка конфигов
сохраняются. Архив с вложенным JAR нужно сначала преобразовать в обычный
архив ресурсов; автоматического рекурсивного поиска вложений нет.

## Проверки

Самостоятельные тесты чтения архивов, без Java/SDK:

```sh
python -m unittest discover -s tests/resources -v
```

После обычной CLDC-сборки запустить существующие тесты M3G с ресурсами:

```sh
QUANTUM_RESOURCE_JAR="$PWD/build/game-resources/resources.jar" \
  JAVA=/path/to/java ECJ_JAR=/path/to/ecj.jar python tests/m3g/run.py
```

`JAVA` должен указывать на настольный JDK с `java.desktop`: ImageIO используется
только тестом для декодирования настоящих PNG. Он **не попадает в MIDlet**.
Вместо ECJ можно использовать установленный `javac`, как и в обычных тестах.
Без `QUANTUM_RESOURCE_JAR` набор работает как прежде, без ресурсного теста.

`GameResourcesTest` перечисляет имеющиеся `levelN.txt`, разбирает их настоящим
`IniFile`, находит `SKYBOX_2D` и создаёт настоящие `RawImage`, `Texture`, `Skybox`.
ImageIO служит декодером тестовых данных, а не заменой игрового LCDUI-загрузчика.
Проверяются реальные параметры панорам, 12 положений камеры на каждую,
16 дождевых частиц, отсутствие повторных загрузок после прогрева и
неизменность исходных пикселей. Конфиги передаются `IniFile` напрямую в CP1251;
запуск полного `LevelLoader`, карт и NPC этот тест **не выполняет**.

M3G в этом наборе — инструментированные API doubles: они позволяют считать
отправки, барьеры и загрузки и проверять состояние, но не воспроизводят
настоящую растеризацию GPU или FPS телефона/J2ME Loader.

## Тестовая сборка с полными ресурсами

В обычную команду `scripts/build_cldc.py` добавлены необязательные аргументы:

```sh
python scripts/build_cldc.py \
  --java /path/to/java --ecj-jar /path/to/ecj.jar \
  --api-dir /path/to/j2me/lib --proguard-jar /path/to/proguard.jar \
  --resource-archive 'q 92 20251201y.jar.zip' \
  --output-dir build/game-resources/game
```

Получатся `Quantum.jar`, `Quantum.jad` и `build-report.json` с хешем архива.
Классы и manifest берутся из текущей сборки, не из загруженной игры.
Файлы из `res/`, если они есть, имеют приоритет над одноимёнными файлами архива.
Без нового аргумента обычная сборка остаётся без внешних игровых ресурсов.
Указанный отдельный output-dir не меняет опубликованные файлы в `downloads/`.
Для реального теста JAR нужно запустить в J2ME Loader или на телефоне.
Настройки доступности уровней/сохранений исходного архива не исправляются
автоматически; наличие 45 конфигов не означает 45 открытых пунктов меню.

## Проверено 18.10.2026

В предоставленном архиве: **505 файлов ресурсов, 45 конфигов уровней,
313 PNG**. Пять конфигов содержат 2D-панораму:

| Уровень | Текстура | Размер | Максимумы D / B / T после прогрева |
| --- | --- | --- | --- |
| 5 | `/skies/sky2.png` | 64×64 | 2 / 0 / 0 |
| 19 | `/skies/shooter_final.png` | 256×64 | 3 / 1 / 0 |
| 27 | `/skies/village_sky.png` | 256×128 | 3 / 1 / 0 |
| 32 | `/skies/city.png` | 256×128 | 3 / 1 / 0 |
| 40 | `/skies/metro dead city.png` | 256×128 | 3 / 1 / 0 |

Это отдельные максимумы на проверенных ракурсах при отрисовке **только неба и
16 дождевых частиц**, без мира/NPC/постэффектов. Не гарантированный максимум
на всех ракурсах: общий контракт панорамы и дождя допускает до четырёх вызовов.
Обработка `lowestDegree` может обрезать viewport; такой фон не считается
полной заливкой и может требовать сохранения предыдущих пикселей (**B:1**).
Это не доказательство CPU-материала и не доказательство дефекта.
Результаты не объясняют автоматически пользовательские D:15/D:119:
для этого нужны проверки полного кадра и его очередей.

Прошли 5 Python-тестов ресурсного архива, **146 PASS-групп M3G**, framebuffer
и settings. Тестовая сборка прошла CLDC preverification; проверено побайтное
совпадение всех 505 ресурсов с архивом и всех 145 классов с опубликованным
BLEND-движком. SDK и тестовые классы в игровой JAR не включены.
Полноценный визуальный запуск игры и замер FPS здесь не выполнены.

Дополнительная диагностика реальной геометрии через `QUANTUM_WORLD_PROBE=1`
описана в [анализе узких мест M3G](m3g-bottleneck-analysis.md): причины разрывов
Fog-пакетов, отказов упаковки и переходов framebuffer между M3G и CPU.

## Дополнительная диагностика Stlkr level13

[Проверка draw-вызовов level13](m3g-level13-check.md) использует отдельный
архив `Stlkr by ebk.jar (1).zip`, реальные House/порталы и начальные объекты.
Флаг `QUANTUM_LEVEL13_PROBE=1`; не смешивать с `QUANTUM_LEVEL41_PROBE`.
Контроль Fog OFF — только локальный изменяющий картинку эксперимент, не правка игры.

[Точное объединение Fog-пакетов](m3g-fog-exact-rebase.md) добавляет
`QUANTUM_FOG_REBASE_REFERENCE=1` — только для временной test-source сборки
с отключённым новым объединением. `tests/m3g/compare_fog_rebase.py` проверяет
все 320 упорядоченных native stream witnesses и инвариантные счётчики.
Это не конфиг игры, не отключение Fog и не сравнение GPU screenshots.

При сборке архива с не-ASCII именами ресурсов build script восстанавливает
их из исходного словаря после ProGuard: версия 6.x может потерять ZIP UTF-8
flag. Preverified classfile bytes не меняются; ресурсы не переименовываются
по догадке. Регрессия проверяет испорченные local/central flags и точные
исходные имя/байты. Все 442 ресурса Stlkr проверены после упаковки.

[Batching спрайтов NPC](m3g-npc-sprite-batching.md) проверяется через
`SpriteBatchTest` и `QUANTUM_SPRITE_BATCH_REFERENCE=1` (test-only reference).
В текущих 80 позах level13 все draw counts и 320 ordered streams остались
прежними; синтетические 70 совместимых billboards дают 3 sprite draws.


## Регрессии CPU-оптимизации ИИ

`python tests/ai/run.py` после CLDC-сборки сравнивает настоящие NPC updates
с исходным action/поиском, включая visibility raycast, маршруты, награды и
очередь скриптов. Физический шаг в AI fixture отключён. Native probes level13
и level41 по-прежнему проверяют упорядоченные потоки/counters, не FPS.
[Методика и ограничения](ai-selection-optimization.md).

## Draw-вызовы Stlkr level12

`QUANTUM_LEVEL12_PROBE=1` включает снимки реального level12 с порталами,
тремя материалами мира, mesh presets, idle NPC и фиксированным дождём.
[Методика, результаты и ограничения](m3g-level12-draw-diagnostic.md).
Флаг `QUANTUM_LEVEL12_FOG_OFF=1` — только контрольный тест в child JVM,
не изменение конфигов или тумана опубликованной игры.

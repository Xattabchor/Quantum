# Пакетирование модельного неба M3G — 18.10.2026

Оптимизирована подача 3D-неба, найденная при [проверке level41](m3g-level41-check.md).
Ресурсы, геометрия, UV, порядок полигонов и исходный Software не изменены.

## Изменение

`M3GSkyRenderer` накапливает соседние совместимые треугольники в пакете
до **192 вершин / 64 треугольников**. Каждый треугольник остаётся отдельным
strip длины 3; соединяющих треугольников нет. VertexArray и CPU-массивы
фиксированного размера, TriangleStripArray кэшируются по числу треугольников.

Граница пакета:

- другой RawImage или режим материала;
- другой исходный UV-scale;
- заполнение буфера;
- конец модели.

Нет сортировки по текстуре: сохраняется существующий painter-order.
Перед сменой материала пакет отправляется **до** обращения к texture cache,
чтобы новый upload/barrier или изменение общего Texture2D не повредили
предыдущему пакету. Прежние ALPHA, ADD, BLEND, MODULATE, MODULATE_X2,
cutout, фильтрация и настройка HW perspective сохранены.

Clipping, scale общих позиций, квантование каждого short и исходный UV-scale
не менялись. При смене UV-scale старые shorts не пересчитываются.
Проверка всей модели до первой отправки, целиковый fallback неподдерживаемого
материала и атомарный rollback при native exception сохранены. Pending-пакет
сбрасывается в finally; камера уровня восстанавливается и при ошибке.

## Level41: до / после

Те же ресурсы из `q 92 20251201y.jar.zip`, 240×320, две диагностические точки,
32 ориентации на точку, четыре компонентных опыта — **256 измеренных кадров**
после прогрева. Это M3G API doubles, не эмулятор растеризации и не FPS телефона.

| Опыт, камера `(0,1155,0)` | D до | D после | Небо до → после | B до → после |
| --- | ---: | ---: | ---: | ---: |
| Только небо + 16 линий дождя, yaw 0 / pitch 85 | 28 | **2** | 27 → **1** | 1 → 1 |
| Небо + мир + дождь, yaw 0 / pitch 0 | 37 | **22** | 16 → **1** | 3 → 3 |
| Небо + мир + дождь, yaw 45 / pitch 0 | 69 | **52** | 18 → **1** | 3 → 3 |
| Небо + мир + дождь, yaw 45 / pitch 30 | 71 | **50** | 22 → **1** | 2 → 2 |

Во всех 64 ракурсах неба оно укладывается в **один native draw вместо 16–27**.
Изолированное небо с дождём даёт **D:2 вместо D:17…28**. Для combined диапазон
в выбранных точках стал D:2…52 вместо D:19…71; это не пределы для всей игры.

По всем 256 случаям автоматически сопоставлены логи до/после: отличаются
только общий D и число D неба. Совпадают native draw мира/дождя/SolidSky,
CPU projection, очереди, причины fallback, разрывы world-пакетов, B, T,
readback и обратные загрузки. После явного прогрева семи изображений T:0.

**B не устранён.** Модельное небо по-прежнему не считается гарантированным
полным непрозрачным фоном: консервативное сохранение framebuffer остаётся.
CPU-fallback мира из-за вершин за камерой/точности не отключён.
Ни повышения FPS во столько же раз, ни устранения всех тормозов не заявляется.

## Проверки

- `SkyTest`: геометрическое покрытие всех треугольников пакета в 168 позах,
  poles, clipping, viewport, FOV/центр, alpha/cutout, animation, camera restore,
  Software и whole-mesh fallback. Сценарий частичного отказа теперь использует
  модель больше одного пакета: ошибка второго draw случается после успешного
  первого, затем проверяется полный CPU replay без повторных native попыток.
- `SkyBatchTest`: 86 эталонных упорядоченных triangle streams, включая 32
  ракурса настоящего skybox5, семь режимов, общий RawImage с разными состояниями,
  нестандартные UV и переполнение пакета. Фиксированы прежние shorts, scale,
  UV-scale, material/camera state и порядок; SHA-256 сверяются с golden-файлом.
  Golden получен запуском исходного M3GSkyRenderer из `51ca34f`, не новым кодом.
- `Level41Probe`: проверяет ровно один native draw неба, неизменность исходных
  пикселей, настоящую WTEX/анимацию, lightmap и House/chunks.
- 148 PASS-групп ресурсного/level41/M3G набора, 141 обычного набора;
  framebuffer/settings и восемь Python resource/profile tests прошли.
- Обычная CLDC-сборка: 145 классов, 1853 метода с кодом, 994 StackMap,
  class version 47.0. **Из прежних 145 классов изменился только
  `code/Rendering/M3GSkyRenderer.class`**, остальные 144 байт-в-байт прежние.
- У полной и engine-only сборок классы одинаковы, все 505 ресурсов полной
  сборки байт-в-байт совпадают с архивом. FrameProfile не включён.

- Соответствующие JAD содержат правильные имя JAR и размер.

Повторить после `scripts/build_cldc.py`:

```sh
QUANTUM_RESOURCE_JAR="$PWD/build/game-resources/resources.jar" \
QUANTUM_LEVEL41_PROBE=1 JAVA=/path/to/java ECJ_JAR=/path/to/ecj.jar \
python tests/m3g/run.py
```

На устройстве проверить ту же точку level41 с Renderer=M3G. Особенно сравнить
D при взгляде в небо; B может остаться прежним. Счётчик FPS/FrameProfile нужен
для отдельного измерения реального выигрыша на телефоне или J2ME Loader.

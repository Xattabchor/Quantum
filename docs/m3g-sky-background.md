# Удаление лишнего B модельного неба — 18.10.2026

> Следующая правка: [отсечение мира для native M3G](m3g-world-clipping.md)
> устраняет оставшиеся world B в этой диагностической выборке. Ниже — результаты
> предыдущего d4ecde5, до world clipping, а не показатели текущей сборки.

Продолжение [пакетирования 3D-неба](m3g-sky-batching.md).
Убран не счётчик, а сохранение/обратная загрузка предыдущего framebuffer,
когда проверенное замкнутое непрозрачное небо полностью заменяет фон.

## Изменение

`SkyCoverage` — API-free консервативная проверка небольшого mesh:

- известные типы полигонов, не более 512 углов;
- каждое ребро принадлежит ровно двум граням; совпадение по координатам,
  поэтому отдельные Vertex на UV-швах не мешают проверке;
- нечётное пересечение тестового луча подтверждает нахождение начала
  координат внутри замкнутой поверхности; неоднозначное попадание на ребро
  или вершину не оптимизируется;
- минимальное расстояние до всех плоскостей треугольников даёт внутреннюю
  сферу; её радиус консервативен и для слегка неплоских четырёхугольников;
- текущий transform, его фактическое 12-битное округление, перенос и масштаб
  учитываются через границы матрицы; весь near viewport должен быть внутри;
- отдельная консервативная граница short-W отклоняет низкую точность упаковки;
- полный viewport и только материал, соответствующий M3G mode0, без нулевых
  texel. ALPHA/ADD/BLEND/MODULATE и другие режимы не объявляются полным фоном.

Топология проверяется один раз, повторно при изменении координат/ссылок
вершин/топологии. Снимок включает и неиспользуемые вершины: они влияют на общий
scale в native sky renderer. Проверка непрозрачности кэшируется по RawImage,
ссылке на массив и размерам, как существующий native texture cache. Изменения
пикселей предполагают замену массива; покадрового сканирования PNG нет.
Нет покадровых framebuffer-аллокаций или второго Image. При нехватке памяти
на certificate сохраняется старый консервативный путь.

Для прошедшего проверку неба:

1. `DirectX7` может отбросить предыдущий pending Image без `getRGB`.
2. Перед первым native batch выполняется полный аппаратный color clear
   цветом первого texel неба, без upload старого `display`.
3. Исходная 3D-модель рисуется поверх, тем же пакетом, с теми же UV/shorts.
   В штатном нативном кадре непрозрачная замкнутая модель закрывает подложку.
4. При ошибке native clear/рисования тот же фон заполняется в selected-M3G
   CPU replay, затем заново рисуется весь исходный sky/world. Поэтому rollback
   не зависит от старого Image, который уже мог быть перезаписан.

Clear не входит в D, как и существующая вспышка грозы. Это реальная отдельная
native API-операция, не бесплатная работа; она проходит через общий `clearSky`
и учитывается в API-времени диагностического FrameProfile. Геометрия/UV и
порядок подачи не меняются. Для исходного Software подложка не добавляется.
Неподтверждённые, открытые, прозрачные, слишком большие, плохо обусловленные
или обрезанные порталом модели продолжают сохранять предыдущий framebuffer.

## Level41: после пакетирования → после удаления B неба

Тот же архив, те же 256 случаев (2 точки × 32 ориентации × 4 компонента),
240×320, явный прогрев семи изображений. Это API-тесты, не FPS телефона.

| Сцена в точке `(0,1155,0)` | D | B до → после | Полных readback/upload до → после |
| --- | ---: | ---: | ---: |
| Только небо + дождь | 2 | **1 → 0** | **1/1 → 0/0** |
| Мир + небо + дождь, yaw 0 / pitch 0 | 22 | **3 → 2** | **3/3 → 2/2** |
| Мир + небо + дождь, yaw 45 / pitch 0 | 52 | **3 → 2** | **3/3 → 2/2** |
| Мир + небо + дождь, yaw 90 / pitch 0 | 41 | **2 → 1** | **2/2 → 1/1** |
| Взгляд вверх без мира, yaw 0 / pitch 85 | 2 | **1 → 0** | **1/1 → 0/0** |

Во всех 64 sky-only ракурсах **D:2, B:0, T:0**. Для combined диапазон B стал
**0…2 вместо 1…3**. В 25 проверенных ракурсах без CPU-отказов мира теперь B:0.
В оставшихся 39 ракурсах сохраняются необходимые CPU-сегменты мира.
Это не утверждение о долях кадров в игре: точки и камеры синтетические.

Автоматическое сравнение всех 256 строк с предыдущим билдом подтвердило:
меняются только B/readbacks/uploads для sky и combined, ровно на единицу.
D, T, проекции, очередь, материалы, world/weather draw, причины fallback,
разрывы пакетов и случаи flash/world+solid неизменны. Все 86 прежних golden
triangle streams совпадают.

**Полностью удалить B мира эта правка не обещает.** Грани, отвергнутые
упаковщиком по behind-camera/weight-precision, должны видеть предшествующие
нативные пиксели и возвращать результат в M3G. Они не пропускаются и не
переставляются. Нужна отдельная корректная замена этого CPU-пути, а не
обнуление счётчика или отключение чтения перед CPU-отрисовкой.

## Проверки и сборки

- `SkyBackgroundTest`: холодное/прогретое небо с дождём без getRGB/drawRGB;
  readback.fail; один Image; явный pause snapshot; смена модели/грозы без
  утечки цвета; portal crop, режимы 1/2/4/5/7/10, cutout, открытая модель,
  камера снаружи, изменение RawImage/массива, геометрии/топологии,
  неиспользуемая дальняя вершина и extreme FOV.

  target освобождён, backend отключён, CPU replay совпадает с эталонным

  PASS-группа с активной frame-profile инструментализацией. Framebuffer,

# Quantum  
J2ME 3D Game engine based on Iceberg 3D.  

Uses software rendering and zone/portal-based culling. Frames are presented through the original MIDP Graphics.drawRGB path.
Supports some kind of scripting (should be replaced with lua!), has its own lightmapper.  
I wrote it when I was just learning Java and OOP, so the code quality is really low, but maybe this engine can be useful to someone.  

## Оригинальный программный рендер

Для Software восстановлен исходный вывод через MIDP `Graphics.drawRGB`,
включая фон паузы и меню. Nokia DirectGraphics и зависимость от Nokia UI API
удалены; второй рендер M3G сохранён.
[Сборка и проверки](docs/build-cldc.md).

## M3G / JSR-184

**M3G-only перенос: этап 2 — native near/far depth bands.**
В контрольных наборах Stlkr geometry CPU dispatches 448 → 0; strict gate проходит.
Софтрендер ещё не вырезан, HUD/оружие не перенесены целиком; downloads прежние.
[Изменения, проверки и ограничения этапа 2](docs/m3g-depth-bands.md) ·
[Контракт режимов и план переноса](docs/m3g-only-migration.md).
Точка возврата до переноса: `b0ee49b`.

Добавлен экспериментальный второй рендер: **Settings → Renderer → M3G**.
По умолчанию работает Software. M3G растеризует поддерживаемые полигоны
и обрабатывает туман материалов 3/6 через native `Fog.LINEAR`, режима 12 —
через `Fog.EXPONENTIAL`. Материалы 9/13 сохраняют baked light/RGB без Fog.
Спрайты сцены (обычные, ADD и alpha)
тоже рисуются M3G-квадами, с анимацией, зеркалированием и туманом.
MUL-спрайты используют native MODULATE; неподдерживаемые материалы сохраняют программный путь.
Панорамное 2D-небо тоже рисуется M3G-квадом с исходным разрешением и кэшем текстуры;
при превышении аппаратных лимитов остаётся CPU fallback.
Небо, мир, постэффекты и погода объединены в одну транзакцию.
GameScreen выводит готовый Image через drawImage без обязательного финального
getRGB; CPU-переходы и legacy/eager API сохраняют readback при необходимости.
Фейковая засветка выстрела и OMNI режима 5 удалены; обычные ADD-спрайты сохранены.
CPU-материалы и cache miss по-прежнему могут создавать необходимые барьеры.
После выбора M3G доступен **HW perspective: ON / OFF** — аппаратная
перспективная интерполяция (по умолчанию ON). Выбор сохраняется отдельно,
применяется после паузы и не меняет PERSQ или Software.
Для NPC и остальных 3D-мешей M3G включён аппаратный backface culling:
`CULL_BACK` с правильным winding; исходное CPU-отсечение сохранено.
Небо, спрайты и экранные эффекты этим куллингом не затрагиваются.
Соседние совместимые полигоны мира и мешей собираются в пакеты до 64 треугольников:
меньше draw-вызовов и native-загрузок вершин, без сортировки по текстурам
и изменения painter-order. Legacy multi-pass эффекты сохраняют отдельные проходы.
У Fog-полигонов добавлена общая бинарная сетка глубины для лучшего batching:
разные глубины и экранные размеры больше не обязаны давать уникальный масштаб.
Если сетка не проходит прежний допуск 1/128, используется исходная упаковка.
В M3G сверху видны `D/B/T`: native draw-вызовы, промежуточные CPU/ресурсные
барьеры, загрузки текстур. По умолчанию включены; переключатель Show QFPS скрывает
и эту строку, Debug включать не нужно. Значения — пики за кадр в окне 250 мс.
Альфа-тест автоматически отключается у полностью непрозрачных native-текстур.
Прозрачные отверстия и alpha blending сохранены; признак вычисляется при upload,
без повторного сканирования текстур каждый кадр.
Градиентное небо (mode 3) в M3G заменено однотонным фоном без переключателя;
цвет берётся из первого texel исходной текстуры. В Software градиент сохранён.
Ключ `BLOOM` действует только в Software; в выбранном M3G bloom отключён.
В M3G туман полигонов и спрайтов выполняется в один native-проход, без CPU
дистанционных коэффициентов и fog-mask текстур. LQ теперь плавный.
Материал 1 в выбранном M3G использует ALPHA по альфа-каналу текстуры, без Fog,
включая CPU fallback/replay. Материал 7 — MODULATE, материал 10 — MODULATE_X2, режим 2 остаётся ADD.
Режим 5 — BLEND с M3G_BLEND_COLOR; 11 — DECAL с белой подложкой.
Статический свет 9/13 сохранён **без дистанционного Fog**. Software исходный.
Виньетка, урон и смерть в выбранном M3G объединены в **один MODULATE quad**
до завершения native-прохода: кэшированная маска до 64×64 LUMINANCE, красный фильтр урона и
затемнение при смерти (вместо grayscale). DoubleBright, как BLOOM, остаётся только
в Software. На прогретом кадре нет CPU-проходов этих эффектов/повторных mask uploads;
при отказе M3G новые эффекты выполняются одним CPU-циклом. Software не менялся.
Границы для mip/перспективы общие; mip по-прежнему выбирается по исходным порогам.
Форматы ресурсов и игровая логика не менялись.

9 и 13 режимы рендеринга включают освещение, которое запекается и сохраняется в файл lightmap.vla
полученный файл можно положить в файлы игры и прописать в карте путь к этому файлу через опцию LIGHTMAP
9 режим - чёрно-белое освещение, 13 режим - более медленное цветное, однако если в 13 режиме полигон освещён чёрно-белым светом он будет рендерится через 9 режим для экономии процессорного времени
Так же есть 10 режим, который подходит для рендеринга *ковров* (пример - 32 уровень)

настройки освещения:

Все цвета указываются перечислением трёх значений через запятую(интенсивность красного синего и зелёного от 0 до 255, если указать только одно значение, то загруженный цвет будет серым с указанной яркостью)
Значения могут быть больше 255, или меньше 0
Пример:
SUN_LIGHT=512,255,0
Яркий оранжевый солнечный свет
SKY_LIGHT=1024
Очень яркий серый свет от неба

AMBIENT_LIGHT
Цвет окружающего света, cтандартная яркость 64

SKY_LIGHT (бывший SKY_LIGHT_INTENSITY)
Цвет света от неба, cтандартная яркость 512

LIGHT_X
LIGHT_Y
LIGHT_Z
Вектор направления солечного света
SUN_LIGHT (бывший SUN_LIGHT_INTENSITY)
Цвет солнечного света, cтандартная яркость 0(солнечный свет отключен)

AO_INTENSITY
Сила оклюзии окружения, cтандартное значение 0
AO_DISTANCE
Расстояние оклюзии окружения, cтандартное значение 2048

GI_RAYS
Глобальная иллюминация, количество отражений света от поверхностей, cтандартное значение 0
GI_INTENSITY
Цвет отражений света, cтандартное значение 768
GI_FALLOFF
Цвет-множитель, на который умножается свет после каждого отражения, стандартное значение 230 (~0.9)
Нужен для затухания света после отражений
GI_LUM_FROM_TEXTURES
Цвет, на который умножаются отражения светящихся текстур(с нулеым режимом рендеринга)
Стандартное значение 0 (светящиеся текстуры не освещаются соседние поверхности)
GI_BW
0/1, стандартное значение 0, включает чёрно-белые отражения света вместо цветных. Может пригодится, когда из-за проблем с производительностью на карте приходится использовать чёрно-белое освещение с отражениями света, однако не получается отказаться от редких цветных источников света и использования 13 режима.
GI_BW_TEX
0/1, стандартное значение 0, аналог GI_BW, опция делает цвета отражающих поверхностей чёрно-белыми, однако оставляет цветные отражения света, за счёт чего на сцене могут быть цветные отражения цветных источников света, а цветные стены никак не будут на них влиять, оставляя цветной свет в строго отведённых под него местах. Рекомендую использовать эту опцию вместо GI_BW.

LIGHT_RAYS
Качество непрямого освещения(небесного света, отражений света и оклюзии окружения)
Стандартное значение - 8, но если включен рейкастинг для просчитывания непрямого освещения, то стандартное качество понижается до 3
Чем выше значение, тем меньше различных артефактов после запекания света, однако само запекание замедляется
LIGHTMAPPER_RAYCASTING
0/1, стандартное значение 0, включает вместо нового метода просчитывания непрямого освещения старый рейкастинг, который работает ~ в 20 раз медленне, однако при использовании старого метода свет намного реже протекает через углы и стыки поверхностей.
Чтобы протеканий было меньше советую соединять вертексы находящихся рядом поверхностей.
SKY_LIGHT_CHEAP
0/1, включает более быстрый способ просчитывания небесного света, с котором меньше протеканий, однако результат получается заметно темнее. Работает только если отключен рейкастинг. Стандартное значение 0.

PHONG_ANGLE
Указывает максимальную разницу в углах между поверхностями, при которой сглаживаются нормали этих поверхностей, значение с плавающей запятой, стандартное значение - 29.6631.
LIGHTMAPPER_ALLROOMS
0/1, стандартное значение 1, включает учитывание затенений из всех комнат, если отключить, то тени будут падать только из соседних комнат. Не влияет на глобальную иллюминацию.

CAMERA_VECTOR_LIGHT
0/1, стандартное значение 0, устаревший мусор для симуляции фонарика
DOUBLE_BRIGHT
0/1, стандартное значение 0, опция для дебагинга, включает двойную яркость


Настройки точечных источников света на карте:
Тип объектов называется LIGHT
POS - позиция(ции) объекта(ов)

Для работы источника света достаточно указать позици и COLOR(и/или BRIGHTNESS)

COLOR
Цвет источника света, указывается так же, как и до этого

BRIGHTNESS
Яркость источника света, если указать, то цвет источника света будет умножен на указанную яркость.
Если COLOR не указан, то вместо него будет использоваться яркость
Стандартное значение 255

DIRECTION
Нормаль направления света (используется если нужно создать прожектор, направленный источник света)
LOOK_AT
Альтернатива DIRECTION, вместо нормали-направления указывается точка, в которую должен светить прожектор

CEILING_FIX
FLOOR_FIX
0-255, стандартное значение 0
Помогает исправить очень тёмные потолки/полы, когда источник света находится слишком близко к ним

ROOM_ID
Номер комнаты, в котором находится источник света. Может пригодится, если нужно поставить источник света на неевклидовой карте
